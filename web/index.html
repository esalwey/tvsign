    General

    A free Apple ID profile lasts 7 days (168 h). The default, 60 h, leaves two and a half days of margin if the Apple TV or this computer is off.

    A phone is often off the network or asleep: 96 h by default, never less than the setting above.

    One request a day to GitHub (tvsign releases), nothing else is sent. When off, no request at all.

    Non-urgent renewals only happen within this range (local time; empty: any time). Ignored when less than 24 h remain, and for a manual renewal. Start = end: all day.

    Signing service

    Used to sign in to Apple. Leave empty: tvsign uses ani.jkcoxson.com and switches to ani2.stikstore.app if it doesn't answer. A custom server must provide Windows anisette-v3 data (Apple refuses Android servers).

    Certificates

    A free Apple account holds 2 development certificates. Revoking one stops the apps signed with it from launching, including those of Xcode, SideStore or AltStore on your iPhone.

    Notifications

    Alerts when a renewal fails or an app is about to expire. Each destination picks the events it receives. Secrets stay on this server and are never shown again.

    Backup

    Export a backup

    Database, Apple sessions, certificate keys and Apple TV pairings.

    Restore a backup

    Replaces apps, Apple TVs and Apple accounts with those of the backup. Your current ones are kept aside on disk.

    A backup contains secrets: anyone holding it can use your Apple ID session. Keep it private, and never run two tvsign instances with the same Apple ID.

    Pair a device

      The TV isn't found? Enter its address

      If your network blocks discovery (separate VLAN, Docker without host network, firewall), give the TV's IP address (Apple TV Settings › Network).

        Import a pairing file

        TV address

        tvsign finds the TV on its own. If your network blocks discovery, or the TV got a new address, enter it here: tvsign then contacts it directly. Leave empty to go back to automatic discovery.

        Apple account

        Preferably use a dedicated Apple ID. The password is not stored: only the session token is.

        tvsign uses, and may revoke, the development certificate of this Apple ID. Apps signed with it by AltStore, SideStore, Sideloadly or Xcode (on an iPhone, for instance) will stop launching. Use an Apple ID that only tvsign uses.

        Developer team

        The team is part of the app's identifier: changing it installs a second copy of the app on the Apple TV.
